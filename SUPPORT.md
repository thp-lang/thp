# THP support

THP is an experimental project maintained on a best-effort basis.

- Ask usage and design questions in
  [GitHub Discussions](https://github.com/thp-lang/thp/discussions).
- Report reproducible bugs with the bug issue form.
- Propose language changes with the design-proposal issue form before writing
  implementation code.
- Report security issues privately as described in [SECURITY.md](SECURITY.md).

Before asking for help, check the
[implementation status](doc/content/guides/implementation-status.md). Behavior
listed as proposed is not expected to work, and undefined PHP behavior is not a
THP compatibility contract.
