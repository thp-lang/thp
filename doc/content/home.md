## Find the right level of detail

### Learn THP

A short path from installation to your first typed application. Start with the
[getting-started guide](thp:guide.gettingStarted).

### Implemented language

Start with the [language overview](thp:guide.languageOverview), then follow the
availability badges to implemented and partially implemented chapters.

### Runtime/API and proposals

Browse the [standard-library overview](thp:std.index). Proposed symbols are
clearly separated from the smaller executable runtime surface.

## Internals

Follow a program through the standalone compiler, bytecode interpreter, and
request runtime in the [internals overview](thp:guide.internalsOverview). The
[implementation status](thp:guide.implementationStatus) remains the single
detailed feature authority.

## Structured documentation

API facts are validated once, inherited members are resolved by the compiler,
and every symbol receives a stable canonical URL.
