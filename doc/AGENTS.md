# Documentation compiler

Documentation sources are strict Markdown files in `content/`. Keep API facts in
frontmatter and prose in Markdown. Every callable has one source file and
inherited methods always link to the declaring type.

Every page declares `availability: implemented | partial | proposed` separately
from the stability `status`. Use `implementation-status.md` as the detailed
feature authority when assigning availability.

Do not edit `dist/`; it is generated by `pnpm build`.

Validate changes with:

```sh
pnpm format:check
pnpm lint
pnpm check
pnpm build
env SITE_URL=https://example.github.io BASE_PATH=/typed-php/ pnpm build
```
