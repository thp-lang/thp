# Security policy

THP is experimental and is not production-ready. Do not use it to process
untrusted programs or expose it as a production web backend.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for the
[`thp-lang/thp`](https://github.com/thp-lang/thp/security/advisories/new)
repository. Do not open a public issue for a suspected vulnerability.

Include affected versions or commits, a minimal reproduction, impact, and any
known mitigations. Maintainers will acknowledge a complete report within seven
days when possible and coordinate disclosure after a fix or documented
mitigation is available.

Only the latest prerelease and the current `main` branch receive security
fixes. Because the project is experimental, response times and compatibility
cannot be guaranteed.
